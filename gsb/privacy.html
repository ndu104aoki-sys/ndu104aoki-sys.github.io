プライバシーポリシー

ジニー → setリスト 入力ブリッジ（Genie Set List Bridge／GSB）
制定：2026年8月30日／最終更新：2026年10月7日

Genie Set List Bridge（以下「本拡張機能」）は、ピュアリオ歯科（以下「当院」）が院内業務のために作成・運用する Chrome 拡張機能です。本拡張機能が扱う情報と、その扱い方を次のとおり定めます。

1. この拡張機能について

予約システム「ジニー」（dentai.net）に表示されている患者の予約情報を読み取り、当院の各医院の Google スプレッドシート（setリスト）へ入力するためのツールです。当院のスタッフが、院内の業務用 Google アカウントで使います。一般向けには提供していません。

2. 当院以外の者はデータを受け取りません

  • 本拡張機能は、当院の Google スプレッドシートとそれに付いている Google Apps Script（いずれも Google のサービス）以外に、データを送信しません。
  • 利用状況の収集・分析・計測は行いません。
  • 広告のための送信は行いません。
  • 当院やその他の者が運営する独自のサーバーに、データを保管しません。

3. 扱う情報

スタッフが右クリックで患者や予約を選んだときにだけ、ジニーの画面から次の情報を読み取ります。

  • カルテ番号
  • 患者の氏名（カナを含む）
  • 予約の日付・時刻、処置名、所要時間、担当スタッフ、予約の状態（来院・未来院・キャンセルなど）

読み取りは右クリックした瞬間に限られます。常時の監視や、画面全体の記録は行いません。ジニーの画面には電話番号など他の情報も表示されますが、本拡張機能はそれらを読み取りません。

あわせて、確認画面に表示するため、setリストに記録されている同じ患者の行（氏名・スキャン日・SM日・セット日・備考など）を読み取ります。

このほか、次の情報を扱います。

  • Google アカウントの許可に伴うアクセストークンと、そのアカウントのメールアドレス
  • 動作の確認用の記録（送信ごとの目印・処理にかかった時間・結果）。患者の情報は含みません

4. 送信先と送信のタイミング

  • 送信先は、当院が設置・管理する各医院の Google Apps Script だけです。Google Apps Script のウェブアプリ（script.google.com）、または Google Apps Script API（script.googleapis.com）に、HTTPS で送ります。
  • 右クリックしたときに、setリストの該当する行を探すため、カルテ番号と医院を送ります。
  • setリストへの書き込みは、スタッフが確認画面で内容を確かめ、書き込みを指示したときにだけ行います。
  • Google Apps Script は、当院の setリストを読み書きするために、Google スプレッドシートと Google Sheets API を使います。

5. Google アカウントの許可について

初めて使うときに、Google アカウントで次の許可を求めます。

  • Google スプレッドシートの参照・編集（https://www.googleapis.com/auth/spreadsheets）
  • アプリがあなたのいないときに実行できるようにする（https://www.googleapis.com/auth/script.scriptapp）
  • メールアドレス（openid・email）

これらは、当院の setリストに付いている Google Apps Script を呼び出し、setリストを読み書きするためだけに使います。メールアドレスは、同じアカウントで許可を取り直すときの目印にだけ使います。

6. 端末に保存する情報

  • 拡張機能の保存領域（chrome.storage.local）に、医院ごとの送信先 URL とアクセス用の合言葉（トークン）、表示の設定、許可したアカウントのメールアドレスを保存します。
  • Google のアクセストークンは、ブラウザを閉じると消える領域（chrome.storage.session）に保存します。
  • いずれもこの端末の中にだけ保存し、Google アカウント間で同期しません。拡張機能を削除すると、これらも削除されます。
  • 患者の情報は保存しません。読み取った内容は確認画面での表示と送信に使った後に破棄し、拡張機能の中に残しません。

7. 送信先に残る情報

  • setリストに書き込んだ情報は、当院の Google スプレッドシートの一部として、当院の管理のもとで保管します。
  • 動作の確認用の記録は、Google Apps Script の一時的な保存領域（最長6時間で消えます）と、当院の Google Cloud プロジェクトのログ（Google Cloud の保存期間の設定に従って消えます）に残ります。患者の情報は含みません。

8. 権限を必要とする理由

  • contextMenus：右クリックメニューを表示するため
  • storage：上記の設定を端末内に保存するため
  • identity：Google アカウントの許可を取り、Google Apps Script API を呼び出すため
  • dentai.net へのアクセス：予約情報を読み取るため
  • script.google.com／script.googleusercontent.com へのアクセス：当院の Google Apps Script（ウェブアプリ）へ送り、答えを受け取るため

9. 医療情報の取り扱いについて

本拡張機能が扱う情報には、患者の氏名と診療の予約日が含まれます。これらは当院の管理下にある情報であり、その取り扱いは当院の規程および関係法令に従います。送信先の Google スプレッドシートおよび Google Apps Script は、当院が適切なアクセス制御のもとで運用します。

10. 第三者への提供

本拡張機能が扱う情報を、販売・譲渡したり、広告や与信の判断に使ったり、第三者に提供したりすることはありません。法令に基づく場合を除きます。

11. Limited Use（限定的な使用）に関する表明

  • 本拡張機能による情報の取り扱いは、Limited Use の要件を含む Chrome ウェブストアのユーザーデータ ポリシーに準拠します。
  • 本拡張機能が Google API から受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • 読み取った情報は、本拡張機能の単一の用途（ジニーの予約情報を、当院の setリストへ入力すること）のためにだけ使い、それ以外の目的では収集・使用・送信しません。

12. 許可の取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、本拡張機能への許可をいつでも取り消せます。拡張機能を削除すると、端末に保存した情報も消えます。

13. 変更

このポリシーを変更する場合は、この文書の「最終更新」を改めます。重要な変更がある場合は、拡張機能の更新時に併せて告知します。
