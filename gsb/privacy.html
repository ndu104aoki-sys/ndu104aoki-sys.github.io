Genie Set List Bridge（GSB）／制定日：2026/10/7

Genie Set List Bridge（以下「本拡張機能」）は、ピュアリオ歯科（以下「当院」）が院内業務のために作成・運用する Chrome 拡張機能です。本拡張機能が扱う情報と、その扱い方を次のとおり定めます。

扱う情報

  • 予約システム「ジニー」の画面に表示されている患者の番号・氏名・スキャン日・SM日・セット日・備考
  • 当院の Google スプレッドシート（setリスト）に記録されている、上記と同じ種類の情報
  • Google アカウントの許可に伴うアクセストークンと、そのアカウントのメールアドレス
  • 動作の確認用の記録（送信ごとの目印・処理にかかった時間・結果）。患者の情報は含みません

使い方

  • 患者の情報は、スタッフが右クリックで操作したときにだけ読み取り、確認画面に表示し、スタッフが書き込みを指示したときに当院の setリストへ書き込むためだけに使います。
  • Google アカウントの許可は、当院の setリストに付いている Google Apps Script を呼び出し、setリストを読み書きするためだけに使います。
  • アカウントのメールアドレスは、同じアカウントで許可を取り直すときの目印にだけ使います。

送り先と保存

  • 患者の情報の送り先は、当院の Google スプレッドシートと、それに付いている Google Apps Script（いずれも Google のサービス）だけです。当院やその他の者が運営するサーバーには送りません。
  • アクセストークンはブラウザを閉じると消える領域に、メールアドレスはそのブラウザの中にだけ保存します。
  • 動作の確認用の記録は、Google Apps Script の一時的な保存領域（最長6時間で消えます）と、当院の Google Cloud プロジェクトのログに残ります。
  • setリストに書き込んだ情報は、当院の Google スプレッドシートの一部として、当院の管理のもとで保管します。

第三者への提供

本拡張機能が扱う情報を、販売したり、広告に使ったり、第三者に提供したりすることはありません。法令に基づく場合を除きます。

Google API から受け取る情報の扱い

本拡張機能が Google API から受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、本拡張機能への許可をいつでも取り消せます。拡張機能を削除すると、ブラウザの中に保存した情報も消えます。
